# gh-pages branch

This branch only exists to serve a redirect from the old GitHub Pages URL
(`https://fakepython.github.io/gymDiscipliner/`) to the current Vercel
deployment (`https://gym-discipliner.vercel.app`).

The path is preserved when redirecting, so deep links like
`/gymDiscipliner/admin` go to `/admin` on the new site.

Source for the live app lives on the `main` branch.
